# Socials

Socials is Capell's free Foundation extension for managing trusted site profiles and placing accessible follow or share links through an explicit widget.

It owns package tables, validates registered networks through an extensible registry, retains legacy metadata during migration, and never injects a footer automatically. Install with `capell:socials-install`, then place the Socials widget in a layout where it is wanted.

The extension has admin, frontend, console, and registry surfaces. Follow and share output is plain accessible links without SDKs, trackers, or remote assets.
