# Socials

Socials is Capell’s free Foundation extension for per-site social profiles and safe follow/share widgets.

- Composer package: `capell-app/socials`
- Install command: `php artisan capell:socials-install`
- Widget: `socials` (follow or share mode)
- Required packages: Core, Admin, Frontend, and Block Library

It keeps package tables authoritative, imports legacy social metadata once without deleting it, and avoids SDKs, trackers, and automatic theme insertion. See [the overview](docs/overview.md) for the product and integration contract.
